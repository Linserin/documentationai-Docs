## 牌堆

牌堆中的每张牌都是一个 `100` 到 `524` 之间的普通整数。全副牌共 108 张，数字本身就编码了颜色和牌面。

## 百位数字代表颜色

把任意一张牌的 ID 除以 100，得到的商就是它的颜色。

| 百位数字 | 颜色 |
| --- | --- |
| 1 | 红色 |
| 2 | 黄色 |
| 3 | 蓝色 |
| 4 | 绿色 |
| 5 | 黑色 |

## 数字牌

每种颜色的牌区共 25 张。数字 0 只有一张，分别是 `100`、`200`、`300`、`400`。

1 到 9 的每个数字都出现两次：一次在 `101`–`109` 区间，一次在 `111`–`119` 区间。2xx、3xx、4xx 沿用完全相同的排布，因此红色 7 是 `107` 或 `117`，黄色 7 是 `207` 或 `217`，依此类推。

算下来每种颜色是 1 张 0 加 18 张数字牌，剩下 6 张留给功能牌。

## 功能牌

末两位为 21 和 31 的是跳过，22 和 32 的是反转，23 和 33 的是 +2。

| 功能 | 末两位 | ID |
| --- | --- | --- |
| 跳过（Skip） | 21、31 | `121`、`131`、`221`、`231`、`321`、`331`、`421`、`431` |
| 反转（Reverse） | 22、32 | `122`、`132`、`222`、`232`、`322`、`332`、`422`、`432` |
| +2（Draw Two） | 23、33 | `123`、`133`、`223`、`233`、`323`、`333`、`423`、`433` |

每种颜色每种功能有两个 ID，三种功能，四种颜色，合计 24 张功能牌。

## 黑色牌

| 区间 | 牌面 |
| --- | --- |
| `511`–`514` | 黑色 +4（Wild Draw Four） |
| `521`–`524` | 黑色牌（Wild） |

每个区间内的四个 ID 功能完全相同。`511` 和 `514` 都是 +4，`521` 和 `524` 都是黑色牌。之所以拆成不同的编号，是为了让同一种牌的四张副本在牌堆里以互不相同的整数存在。

## 过牌 1000

`1000` 表示过牌。它永远不在牌堆里，也没有颜色。

## 读取牌的 ID

```go
color := card / 100          // 1 红、2 黄、3 蓝、4 绿、5 黑
number := (card % 100) % 10  // 0 到 9
isWild := card/100 == 5
```

以 `223` 为例：`223 / 100` 得 2，所以是黄色。`223 % 100` 是 23，属于功能牌后缀，而 `23 % 10` 是 3，因此是 +2。最终是黄色 +2。

以 `513` 为例：`513 / 100` 得 5，说明是黑色牌。`513 % 100` 是 13，落在 `511`–`514` 区间，所以是黑色 +4。此时 `number` 表达式返回 3，但百位数字已经说明这张牌不是数字牌。
